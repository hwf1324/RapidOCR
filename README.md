# Rapid OCR

This add-on is intended solely for testing the recognition performance of the Paddle OCR ONNXRuntime model.

* Author: hwf1324 <1398969445@qq.com>
* Compatibility: NVDA-2026.1 or later

## Usage

This add-on directly replaces Windows OCR's recognition gestures for testing purposes. During recognition, it automatically downloads the model selected in the Paddle OCR settings panel, which may take some time.

The settings panel offers limited options. You may modify the contents of `models\RapidOCR\config.yaml` in your user configuration folder. Note that certain option combinations may be invalid. Refer to Rapid OCR's documentation for specific parameters.

## RapidOCR Documentation

Full documentation can be found on [docs](https://rapidai.github.io/RapidOCRDocs/), in Chinese.
